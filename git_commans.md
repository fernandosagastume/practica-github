Describe que hacen los siguientes comandos de git, escribe su descripcion al frente en una sola linea.

git status: Este comando se usa para obtener el estado actual del repositorio

git clone: Descarga una copia de un repositorio remoto a el equipo local.

git pull: Trae los cambios del repositorio remoto y los integra en la rama local.

git checkout: Permite cambiar de rama a una versión específica.

git log: Muestra el historial de commits de la rama actual.

git branch: Lista, crea o elimina ramas del repositorio.

git add: Agrega los cambios de los archivos al área de preparación para incluirlos en el próximo commit.

git commit: Guarda en el los cambios realizados localmente una instantánea de los cambios preparados, acompañada de un mensaje descriptivo.

git push: Envía los commits de la rama local al repositorio remoto.

git merge: Combina los cambios de otra rama en la rama actual.
